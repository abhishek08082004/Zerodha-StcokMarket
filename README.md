# Zerodha Stock Market 🚀

A stock market web application inspired by Zerodha, built to explore modern web development through a structured frontend, backend, and dashboard architecture.

## 📌 Overview

Zerodha Stock Market is a web development project inspired by the Zerodha trading platform. It focuses on building a clean user interface and organizing application components into separate modules for better maintainability and scalability.

## ✨ Project Structure

- **Frontend** — Main user interface.
- **Backend** — Server-side application and API logic.
- **Dashboard** — Separate dashboard module.

## 🛠️ Tech Stack

The technologies used in this project can be found in the respective module configurations.

- Frontend Development
- Backend Development
- API Integration
- Git & GitHub

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/abhishek08082004/Zerodha-StcokMarket.git
cd Zerodha-StcokMarket
```

**2. Install dependencies**

Run the following commands in separate terminals:

```bash
cd backend
npm install
```

```bash
cd frontend
npm install
```

```bash
cd dashboard
npm install
```

**3. Run the application**

Start each module using the scripts defined in its respective `package.json`. Configure the required environment variables before starting the backend.

The goal of this project is to practise full-stack web development, frontend-backend integration, and modular application design.
